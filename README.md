# Christ-loisele Atidegla

Developer tooling for AI coding agents. I build the skills, audits, and lists that make agent harnesses safer to ship with. Mostly Laravel and Next.js, in English and French.

### Currently

- **skillbelt**: portable agent skills for secure coding and translation parity. One install, and they work across Claude Code, Codex, Cursor, Gemini CLI and Antigravity.
- **awesome-laravel-ai**: every actively maintained Laravel AI package, with star and install counts that refresh themselves daily instead of rotting.
- **mcpaudit**: security auditing for MCP servers, mapped to OWASP.

### Stack

PHP, TypeScript, Node. Security review is the thread through most of it.
